# Vereinskasse

Kassen-App für Theke und Bratwurststand bei Vereinsfesten und Spielen: Artikel antippen, buchen, Rückgeld, Kassenbestand, PDF-Abrechnung, Archiv. Läuft als Web-App auf dem Handy (hoch und quer), mit Login und gemeinsamen Daten über Firebase.
